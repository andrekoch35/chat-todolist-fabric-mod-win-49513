## Overview

Chat ToDo List Fabric Mod is a Minecraft Java client mod built for players who want a lightweight task-list workflow inside the game chat. It uses chat-based task lists to organize goals, track progress, and handle checklist-style interactions without leaving the play session.

The mod also includes local JSON editing, which makes it easier to adjust list content and structure directly on the client side. Version 1.2.0 focuses on the Fabric client environment and centers on simple task management, interactive checklist behavior, and editable local data handling.
